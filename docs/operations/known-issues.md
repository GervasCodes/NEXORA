## Limitations (by design or scope)

- Revenue mechanisms (commission, subscriptions, sponsorship) ship disabled; production state unknown.
- No native mobile apps; PWA only.
- Currency model is TZS with USD only for PayPal and payout conversion.
- Redis is optional; without it, delivery-offer expiry is not durable.
- English and Swahili only.
- Admin model has two levels; no fine-grained admin permissions.

## Not verified by this audit

Production configuration and data; real provider behaviour; end-to-end browser journeys; load and performance; legal compliance; accessibility beyond automated checks; object-level authorization in general.
